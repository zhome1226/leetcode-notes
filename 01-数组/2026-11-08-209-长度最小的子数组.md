# 209. 长度最小的子数组：滑动窗口

- 链接：[LeetCode 209](https://leetcode.cn/problems/minimum-size-subarray-sum/)
- 日期：2026-11-08
- 状态：🟡（学习题解；尚未独立默写与提交验证）

## 题意：子数组必须连续

给定正整数数组 `nums` 和正整数 `target`，找到总和大于等于 `target` 的最短连续子数组，返回长度；不存在时返回 `0`。

子数组必须保持原来的顺序，且中间不能跳过元素，但可以从任意位置开始。例如 `[2, 3, 1, 2, 4, 3]` 中，`[3, 1, 2]` 和最后的 `[4, 3]` 都是子数组；跳过中间元素选第一个 `2` 和后面的 `4` 则不符合要求。`target = 7` 时，最后的 `[4, 3]` 长度为 `2`，且没有单个元素达到 `7`，所以答案是 `2`。

## 滑动窗口是什么

滑动窗口是在数组或字符串中维护一段**连续区间**，用左边界 `left` 和右边界 `right` 表示它。边界移动时，只处理新进入或刚离开的元素，避免每次从头计算整个区间。

本题窗口为 `nums[left:right + 1]`，左右端点都包含在内，因此长度是 `right - left + 1`。这里只用切片描述区间，实际代码通过下标维护窗口，不创建切片。

窗口常见两种用法：

| 类型 | 边界如何移动 | 应用场景 |
|---|---|---|
| 固定长度 | 右边加入一个，左边移出一个，保持长度为 `k` | 长度为 `k` 的连续子数组的最大和、固定长度平均值 |
| 可变长度 | 根据当前是否满足条件决定扩大或缩小 | 本题的最短达标子数组、无重复字符的最长子串 |

遇到“连续子数组 / 子串”以及“最长、最短、固定长度”等描述时，可以考虑滑动窗口；但还需要判断边界移动后能否有规律地调整条件，不能只凭关键词套用。

## 本题为什么适合滑动窗口

数组中的数都是正整数，所以右端加入元素，窗口和会增大；左端移出元素，窗口和会减小。

总和不足时，向右扩大窗口；总和达标时，先记录当前长度，再从左边缩小，尝试找到更短的答案。左右边界都只往右走，不需要退回起点。

如果允许负数，这种规律就不成立。例如 `target = 3`、`nums = [1, -1, 3]`，照搬本题逻辑会先记录长度 `3`，移出 `1` 后和变成 `2` 就停止收缩，从而漏掉最后的 `[3]`。含负数的最短达标子数组需要其他方法，不能直接套用这里的代码。

## 已学习的代码

下面保留本次学习的题解写法，参数 `s` 就是题目里的 `target`。

```python
from typing import List

class Solution:
    def minSubArrayLen(self, s: int, nums: List[int]) -> int:
        l = len(nums)
        left = 0
        right = 0
        min_len = float('inf')
        cur_sum = 0

        while right < l:
            cur_sum += nums[right]  # 右端元素进入窗口

            while cur_sum >= s:
                min_len = min(min_len, right - left + 1)  # 先记录答案
                cur_sum -= nums[left]  # 再尝试缩短窗口
                left += 1

            right += 1

        return min_len if min_len != float('inf') else 0
```

## 本次学习疑问：减掉左端后，不够 target 了怎么办

这是正常情况。内层 `while` 每次开始前都会重新检查 `cur_sum >= s`；减完不够，就结束内层循环，继续向右扩大。之前记录的有效长度仍保存在 `min_len` 中。

以 `target = 7`、`nums = [2, 3, 1, 2, 4, 3]` 为例：

| 操作 | 当前窗口 | 总和 | 已记录的最短长度 |
|---|---|---:|---:|
| 右端扩到下标 3 | `[2, 3, 1, 2]` | 8 | 先记录 4 |
| 移出左端的 2 | `[3, 1, 2]` | 6 | 仍是 4；退出内层循环 |
| 加入右边的 4 | `[3, 1, 2, 4]` | 10 | 仍是 4 |
| 移出左端的 3 | `[1, 2, 4]` | 7 | 下一次内层循环记录 3 |
| 移出左端的 1 | `[2, 4]` | 6 | 仍是 3；退出内层循环 |
| 加入右边的 3 | `[2, 4, 3]` | 9 | 仍是 3 |
| 移出左端的 2 | `[4, 3]` | 7 | 下一次内层循环记录 2 |
| 移出左端的 4 | `[3]` | 3 | 仍是 2；退出内层循环 |

关键顺序是：**达标 → 记录长度 → 移出左端 → 再检查是否达标**。不能把记录答案放到减法之后，否则可能在窗口已经不达标时记录长度。

## 复杂度

时间复杂度是 `O(n)`。虽然有两层 `while`，但 `right` 最多前进 `n` 次，`left` 在整个过程中也最多前进 `n` 次；内层循环不会为每一个 `right` 都从头遍历。

额外空间复杂度是 `O(1)`，只维护边界、窗口和与最短长度。

## 容易错的地方

- 用 `>=` 判断达标，总和恰好等于目标也算。
- 当前区间包含左右两个端点，长度要加 `1`。
- 内层用 `while` 持续缩小，只用 `if` 会漏掉同一右端下更短的窗口。
- 移出左端元素时，先减 `nums[left]`，再执行 `left += 1`。
- 找不到答案时，返回 `0`，不要返回无穷大。

`float('inf')`、循环写法比较和末尾条件表达式详见 [Python 刷题常用写法](../00-算法基础/Python刷题常用写法.md)。

## 904. 水果成篮：最多两种元素的最长连续子数组

- 链接：[LeetCode 904](https://leetcode.cn/problems/fruit-into-baskets/)
- 日期：2026-11-08
- 状态：🟡（学习题解；待独立默写与提交验证）

### 题意与窗口思路

水果编号表示种类，不是数量。两个篮子各装一种水果，数量不限；从任意位置开始，每棵树摘一个并连续向右，不能跳过中间的树。因此，本题就是找**最多包含两种元素的最长连续子数组**。

例如 `[1, 2, 1]` 有两种水果、三个水果，可以全部收集；`[1, 2, 3, 2, 2]` 中，最长合法区间为 `[2, 3, 2, 2]`，长度是 `4`。

处理顺序固定为：加入右端水果并增加计数；如果超过两种，就不断从左边移出水果；窗口恢复合法后，更新最大长度。

### 用字典维护窗口中的数量

Python 的字典 `dict` 是一种哈希表。本题用“水果种类 → 在当前窗口中的数量”维护窗口状态：

```python
count = {1: 2, 2: 1}
```

表示当前窗口中水果 `1` 有两个，水果 `2` 有一个。`len(count)` 是种类数，`right - left + 1` 是窗口长度，也就是水果总数。

`set` 只能记录有哪些种类，不能直接记录每种水果的数量。字典能够判断移出一个水果后，这种水果是否还留在窗口中。每次从左边只移出一个水果，将其数量减一；只有数量变成 `0` 时，才删除对应的键。

### 本次思路中需要修正的三个地方

**1. 新水果不在 `seen` 中，不一定要移动 `left`。**

例如 `[1, 1, 2]`，加入 `2` 后只有两种水果，第二个篮子还可以装它。只有出现第三种水果时，才需要缩小窗口。

**2. 出现第三种水果时，`left += 1` 可能不够。**

例如 `[1, 1, 2, 3]`，移出第一个 `1` 后变成 `[1, 2, 3]`，仍有三种；再移出一个 `1`，变成 `[2, 3]`，才恢复合法。因此要用 `while len(count) > 2` 持续收缩，不能只用一次 `if`。

这里移除的是 `fruits[left]` 对应的一个水果，不能直接删除最早那种水果的整个字典记录。例如 `[1, 2, 1, 3]` 移出第一个 `1` 后，窗口里仍然有一个 `1`；还要继续移出左边的 `2`，才变成合法的 `[1, 3]`。

**3. 记录最大长度时，窗口必须已经合法。**

加入第三种水果后，先收缩到最多两种，再执行 `max_len = max(max_len, right - left + 1)`，否则会把不合法的窗口长度算成答案。

### 已学习的代码

```python
from typing import List

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        count = {}
        left = 0
        max_len = 0

        for right in range(len(fruits)):
            fruit = fruits[right]
            count[fruit] = count.get(fruit, 0) + 1

            while len(count) > 2:
                left_fruit = fruits[left]
                count[left_fruit] -= 1

                if count[left_fruit] == 0:
                    del count[left_fruit]

                left += 1

            max_len = max(max_len, right - left + 1)

        return max_len
```

`get`、字典计数与 `del` 的基础写法见 [Python 刷题常用写法](../00-算法基础/Python刷题常用写法.md)第 16—18 节。变量名统一使用 `left_fruit`，表示当前要移出的那一个水果的种类。

### 与 209 题的区别

| 题目 | 窗口要求 | 何时收缩 | 何时记录答案 |
|---|---|---|---|
| 209：长度最小的子数组 | 总和 ≥ target | 总和达标时，尝试继续缩短 | 收缩前，窗口达标时 |
| 904：水果成篮 | 最多两种水果 | 出现第三种水果时 | 收缩后，窗口恢复合法时 |

209 题靠正数保证窗口和的变化规律；904 题维护的是种类数，整数编号的大小和正负都不影响计数逻辑。滑动窗口是否适用，要看维护的条件，不能将 209 的正数要求套到所有题目上。

### 复杂度与复习

时间复杂度是 `O(n)`，左右指针各最多向右移动 `n` 次，字典操作的平均时间为 `O(1)`。额外空间为 `O(1)`，因为字典最多临时保存三种水果，收缩后至多保存两种。

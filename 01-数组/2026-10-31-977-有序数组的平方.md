## 题意

给定一个按非递减顺序排列的整数数组 `nums`，返回每个元素平方后组成的、仍按非递减顺序排列的新数组。

例如：

```python
nums = [-4, -1, 0, 3, 10]
# 结果：[0, 1, 9, 16, 100]
```

## 我的思路：双指针，从结果数组末尾填充

最开始想到的是：先遍历数组，把每个数平方，再调用 `sort()`。这个方法正确，但时间复杂度是 `O(n log n)`。

更优的方法利用了原数组已经有序这一条件：

- 负数平方后会变成正数，原数组平方后不一定仍有序。
- 平方后的最大值，一定来自原数组两端之一（最左边的负数或最右边的正数）。
- 每次比较左右两端的平方，把较大的那个放进结果数组当前最右侧的空位。
- 结果数组从右往左填，原数组的左右指针向中间靠拢。

### 三个指针的分工

| 指针 | 初始位置 | 作用 |
|---|---:|---|
| `i` | 0 | 原数组左指针 |
| `j` | `len(nums) - 1` | 原数组右指针 |
| `k` | `len(nums) - 1` | 结果数组的写入位置 |

### 正确代码

```python
class Solution(object):
    def sortedSquares(self, nums):
        i = 0
        j = len(nums) - 1
        k = len(nums) - 1

        res = [0] * len(nums)

        while i <= j:
            left = nums[i] * nums[i]
            right = nums[j] * nums[j]

            if left > right:
                res[k] = left
                i += 1
            else:
                res[k] = right
                j -= 1

            k -= 1

        return res
```

注意：每轮只确定并写入一个最大平方数；选择左边就移动 `i`，选择右边就移动 `j`；无论选择哪边，`k` 都要减一。

## 复杂度

- 时间：`O(n)`。左右指针总共只向中间移动，每个元素最多处理一次。
- 空间：`O(n)`。创建了一个长度为 n 的结果数组。

## 我踩过的坑

1. **空列表不能直接按下标赋值。**

   `res = []` 后直接写 `res[0] = 1` 会报 `IndexError`，因为列表里还没有第 0 个元素。需要提前分配长度：`res = [0] * len(nums)`；或者使用 `append()` 从末尾添加。

2. **长度不是最后一个下标。**

   若 `len(nums) == 5`，合法下标是 0 到 4，最后一个下标是 `len(nums) - 1`，不是 `len(nums)`。

3. **不要覆盖仍要参与比较的原数组。**

   如果一边平方一边写回 `nums`，可能把后续还需要比较的原始数字覆盖掉。这里用 `res` 存结果，保留 `nums` 不变。

4. **每轮只填一个位置。**

   比较两端后，只把较大的平方写入 `res[k]`。不要同时写 `res[k]` 和 `res[k-1]`，因为下一轮还要重新比较剩下的两端。

5. **移动正确的指针。**

   - 取左端平方：`i += 1`
   - 取右端平方：`j -= 1`
   - 写入一个结果后：`k -= 1`

   不能每轮无条件只移动 `j`，也不能忘记移动 `k`。

6. **循环条件要包含相遇的情况。**

   用 `while i <= j`，这样当左右指针相遇时，最后一个元素也会被处理。若写 `i < j`，会漏掉中间元素。

## 补充：时间复杂度与排序

### 先平方再排序

```python
for i in range(len(nums)):
    nums[i] = nums[i] * nums[i]
nums.sort()
```

- 平方循环：`O(n)`。
- Python 的 `list.sort()`：平均和最坏情况 `O(n log n)`；最好情况（已有序或接近有序的输入）可达到 `O(n)`。
- 合起来：`O(n) + O(n log n) = O(n log n)`。

Python 的 `list.sort()` 使用 Timsort。它会利用输入中已经存在的有序片段；不要把它简单等同于纯粹的归并排序。若分析实际辅助空间，Timsort 最坏情况下需要 `O(n)` 临时空间。

### 为什么归并排序是 O(n log n)？

归并排序先把数组不断二分，直到每组只剩一个元素；再把两个有序小数组合并成一个更大的有序数组。

- 每一层合并时，所有元素合计最多处理 O(n) 次。
- 数组每次减半，拆分层数约为 `log₂ n`。
- 因此总时间复杂度为 `O(n log n)`。

注意：这是用归并排序解释 `n log n` 的直观来源；Python 的 `sort()` 实际使用的是 Timsort。

### 两个有序数组怎样合并？

例如 `A = [3, 8]`、`B = [2, 6]`：

1. 比较 3 和 2，取 2。
2. 比较 3 和 6，取 3。
3. 比较 8 和 6，取 6。
4. B 用完，把 A 剩余的 8 接到末尾。

得到 `[2, 3, 6, 8]`。合并两个有序数组只需线性扫描，复杂度为 `O(len(A) + len(B))`。

```python
def merge(A, B):
    i = 0
    j = 0
    result = []

    while i < len(A) and j < len(B):
        if A[i] <= B[j]:
            result.append(A[i])
            i += 1
        else:
            result.append(B[j])
            j += 1

    result.extend(A[i:])
    result.extend(B[j:])
    return result
```

## 补充：C++ 的 `k--` 与 Python

C++ 中：

```cpp
result[k--] = A[j] * A[j];
```

是先使用当前的 `k` 作为下标，再让 `k` 减一。对应的 Python 写法是：

```python
result[k] = A[j] * A[j]
k -= 1
```

Python 没有 `k--` 或 `--k` 这种自增、自减运算符。

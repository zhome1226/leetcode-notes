## 1. 283. 移动零

题目要求把数组里的 0 挪到末尾，非 0 相对顺序不变，而且必须**原地改** `nums`，不能 return 一份新列表。

核心是双指针：`i` 从左扫到右；`j` 表示「下一个非 0 该放的位置」。扫到非 0 时，把 `nums[i]` 写到 `nums[j]`，然后 `j += 1`。扫完后，从下标 `j` 到末尾全部写成 0。

```python
class Solution(object):
    def moveZeroes(self, nums):
        j = 0
        for i in range(len(nums)):
            if nums[i] != 0:
                nums[j] = nums[i]
                j += 1
        for k in range(j, len(nums)):
            nums[k] = 0
```

记住：遇到 0 什么都不用做；不要在 `else` 里乱挪 `nums[j+1]`。

## 2. 26. 删除有序数组中的重复项

有序数组去重，同样原地改，返回去重后的新长度。慢指针 `slow` 表示「当前唯一段的最后一个下标」；快指针 `fast` 从 1 扫到末尾。当 `nums[fast] != nums[slow]` 时，先把 `slow` 加一（挪到下一个空位），再把新值写进去。最后返回 `slow + 1`。

```python
class Solution(object):
    def removeDuplicates(self, nums):
        if not nums:
            return 0
        slow = 0
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow]:
                slow += 1
                nums[slow] = nums[fast]
        return slow + 1
```

用 `[1,1,2]` 走一遍：先写再 `slow+=1` 会把第一个 `1` 盖成 `2`，变成错答案；必须先挪 `slow` 再赋值。

记住：不要写 `nums[fast+1]` 去比下一个，最后一个下标会越界；和 `nums[slow]` 比更稳。

## 3. 844. 比较含退格的字符串

`#` 表示退格，删掉前一个字符，不是「跳过自己」。Python 字符串不能原地改下标，用列表当栈最直观：不是 `#` 就 `append`；是 `#` 且栈非空就 `pop`。对 `s`、`t` 各做一遍再比较。

可以把「消化字符串」写成内嵌函数，外层方法调用两次：

```python
class Solution(object):
    def backspaceCompare(self, s, t):
        def build(char):
            stack = []
            for c in char:
                if c != '#':
                    stack.append(c)
                elif stack:
                    stack.pop()
            return stack
        return build(s) == build(t)
```

记住：内嵌函数不要写 `self`；`self` 只给类的方法用。

## 4. 今日补上的 Python 基础

**`range(n)`** 是左闭右开：`range(4)` 得到 0、1、2、3，不含 4。

**空列表不能按下标写。** `seen = []` 再写 `seen[0] = x` 会越界；要么 `seen = [0] * len(nums)` 先开满，要么用 `append`。

**`nums = seen` 改不了外面的数组。** 这只是让函数里的名字指向新对象；要改原列表内容，用 `nums[i] = ...` 或 `nums[:] = seen`。

**`append` / `pop`：** 把列表想成一摞盘子，`append` 往上加，`pop` 拿走最上面一个。

**`if stack:`** 判断的是「列表是否非空」。空列表 `[]` 在 if 里算假，但它不是 `None`；`None` 表示根本没有这个对象。

**`elif` 和 `else`：** `elif` 还要再判断条件；`else` 是兜底。`elif stack: stack.pop()` 等价于 `else: if stack: stack.pop()`，避免空栈 pop 报错。
